# Human review

Open [quick-review.html](quick-review.html) for rapid quality ratings, or [review.html](review.html) for detailed validity review. Both are standalone browser tools with embedded public questions; no model or server is required.

Export progress regularly and import it when moving browsers or files. `ratings.csv` is a blank template, not completed review data. Keep exported ratings local and separate from model predictions. Review material must not be used as agent input.
